macromac

Native macOS macro recorder and JSON runner for automating real desktop workflows.

Execution Engine

Records mouse and keyboard input over live applications, stores it as editable JSON, and replays it with precise synchronization blocks.

  • Fixed delays & shell commands
  • File-change signals
  • Shell polling conditions
  • Headless runner mode

Security & Trust

Macro is powerful because it can observe and synthesize real desktop input. Requires macOS Accessibility and Input Monitoring permissions.

  • JSON runner is trusted code
  • No untrusted JSON execution
  • Zero hidden app telemetry
  • Local execution only

System Status & Architecture

SYSTEM ONLINE - macOS 13+ / Swift 5.9+

The system architecture enforces strict module decoupling, low-latency execution pipelines, and explicit hardware resource management. It is universal in the low-level sense: if a workflow can be driven by mouse, keyboard, files, and shell commands, Macro can represent it.

$ xcode-select --install
$ git clone https://github.com/Jirnyak/macromac.git
$ cd macromac
$ swift run macro
